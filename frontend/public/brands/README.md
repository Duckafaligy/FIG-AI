# Brand assets

## Google G

- File: `google-g.png`
- Source: [Google Identity's official Google G asset](https://developers.google.com/static/identity/images/g-logo.png)
- Downloaded: September 14, 2026.
- Context: Google's [Sign in with Google Branding Guidelines](https://developers.google.com/identity/branding-guidelines), which links this exact image under “Google logo in the Sign in with Google button.”
- Usage: The original PNG is stored without modification and shown beside “Continue with Google” in the white authentication button. The image keeps its original aspect ratio and standard colors; the button remains equally prominent to the other authentication provider.
- Rights: Google retains rights in its brand features. This is an official authentication brand asset used under the linked branding guidance, not a project-owned logo or a general-purpose open-source icon. The documentation page's content/code licenses should not be treated as a separate license to Google's trademarks. See the [Google Brand Resource Center](https://about.google/brand-resource-center/) for uses beyond this sign-in context.

The authentication button is presently a clearly labeled frontend preview. Integrating Google Identity Services and checking its current button requirements remains part of the backend authentication work.
